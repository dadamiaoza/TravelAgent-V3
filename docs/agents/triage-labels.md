# Triage 标签

各 skill 使用 5 个标准 Triage 角色。本文件将这些角色映射到本项目实际使用的标签字符串。

| Skill 中的标签 | 本项目标签 | 含义 |
| -------------- | ---------- | ---- |
| `needs-triage` | `needs-triage` | 待维护者评估 |
| `needs-info` | `needs-info` | 等待提问者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完备，AI Agent 可接手 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 决定不做 |

当 skill 提到某个角色（如"打上 AFK-ready 标签"），请使用此表中对应的标签字符串。

如需自定义，直接编辑右边这列。
