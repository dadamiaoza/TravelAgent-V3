# Agent-API 集成模式：同步 + 异步 + SSE 混合

## 决策

Agent 暴露出三种调用模式，按耗时选择：轻量操作（<3 秒）走同步 `agent.invoke()`，直接返回结果；重操作（行程生成、路线优化）走异步任务——API 创建 `planning_job` 后立即返回 `job_id`，Agent 在后台执行，前端通过 `GET /jobs/{id}` 轮询；异步任务同时支持 SSE 流式推送进度（"正在解析...正在生成...已完成"）。

## 为什么

- 纯同步：简单，但 Agent 调用 LLM + 外部 API 可能耗时 5-30 秒，HTTP 连接超时风险高
- 纯异步：可靠，但时效校验这种 1 秒操作等轮询体验差
- 混合模式取两者优势——快的立即响、慢的异步不阻塞、SSE 让用户感知进度
